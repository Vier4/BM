# BM — музыка и подкасты

Музыкальное приложение BM: группы BM, песни от ИИ, архивная музыка и подкасты NASA.

**Открыть:** https://vier4.github.io/BM/

- **Группы BM** — «Полярный трамвай», «Ферма снов», «Гранитные чайки», «Лиловый октябрь». Песни и тексты © BM.
- **Вход через BOS** — аккаунт B ID из [BOS](https://vier4.github.io/BOS/). Можно войти или создать новый B ID прямо в BM.
- **BM Премиум** — бесплатная подписка: открывает песни групп BM и подкасты.
- **Песни на стихи** — встроенный плейлист: «Уж небо осенью дышало» (Пушкин) и «Я вернулся в мой город, знакомый до слёз» (Мандельштам). Стихи поёт синтезированный голос (`tools/bm_voice.py`). Песни и стихи — в `js/poem-songs-data.js`, mp3 — в `music/poems/`.
- Поиск, плейлисты, тексты песен.
- **Пометка E (Explicit)** — у песен с матом или грубыми словами. В аккаунте, в разделе «Ограничения», такие песни можно запретить на устройстве.

Работает без сервера: всё хранится в браузере. BM и BOS лежат на одном сайте `vier4.github.io`, поэтому BM видит аккаунт BOS.

## Как добавить песни групп BM
Сейчас у всех 12 песен есть инструментальные версии — их записывает `tools/make_band_songs.py`
(нужны numpy, scipy и lameenc). Версию с вокалом можно записать в Suno:
Инструкция для Suno — [music/bands/КАК_ЗАПИСАТЬ_ПЕСНИ.md](music/bands/КАК_ЗАПИСАТЬ_ПЕСНИ.md).
Готовый mp3 кладётся в `music/bands/<группа>/<песня>.mp3`.

## Запуск на компьютере
Двойной клик по `Запустить BM.command` (нужен Python 3) — BM откроется на http://localhost:8765.
